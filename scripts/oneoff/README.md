# One-off / одноразовые скрипты

Эти скрипты были использованы для выполнения одноразовых задач и не требуют
поддержки. Они помечены как «устаревшие» после выполнения задачи.

## Файлы

- **check_b2_state.py** — проверка состояния батча B2 (хеши, размеры модулей).
  Устарел после выполнения B2.
- **delete_b2_methods.py** — автоматическое удаление 18 методов батча B2 из engine.py.
  Устарел после выполнения B2.
